## 1. 阶段目标

实现 POST /api/chat 完整链路。这是整个项目的**核心验收阶段**——一次调用后：

1. 返回 OpenAI 兼容格式结果（含 usage + cost）
2. 数据库产生调用记录（api_usage_logs）
3. Redis 产生统计数据
4. 模拟器后台持续生成数据，Dashboard 未来可直接消费

## 2. 整体调用链路

```
POST /api/chat  (Authorization: Bearer sk-xxx)
    │
    ▼
[参数校验] → 校验 model 必填、messages 必填、非空
    │
    ▼
[API Key 校验 middleware] → key_prefix 查询 + bcrypt 比对 → 注入 api_key_id / project_id 到 context
    │
    ▼
[额度检查 middleware] → Redis GET quota:key:{id}:{date}:tokens → 超限返回 429
    │
    ▼
[Chat Handler] → 参数绑定 → 调用 Chat Service
    │
    ▼
[Chat Service / Mock Model] → 匹配模型 → 生成模拟回复 + Token 用量 + 时延 + 费用
    │
    ▼
[Usage Collector] → 同步写入 api_usage_logs → 异步 goroutine 更新 Redis 指标
    │
    ▼
返回 OpenAI 兼容格式 JSON (含 usage.cost)
```

## 3. 本阶段实现内容

| # | 内容 | 文件 | 说明 |
|---|---|---|---|
| 1 | API Key 校验中间件 | `internal/middleware/api_key.go` | key_prefix 查库 + bcrypt 比对 + 注入 context |
| 2 | 额度检查（合并） | 同上 | Redis 查询 + 超限 429 |
| 3 | Chat Service | `internal/service/chat_service.go` | 模型匹配 + 模拟回复 + Token 估算 + 费用计算 + 日志写入 + Redis 更新 |
| 4 | Chat Handler | `internal/handler/chat.go` | 参数绑定 + 调用 service + 错误映射 |
| 5 | 模拟器 | `internal/simulator/simulator.go` | 独立 goroutine，3~6 秒间隔自动生成调用数据 |
| 6 | 路由注册 | `internal/router/router.go` | 注册 /api/chat + API Key 中间件 |
| 7 | 入口集成 | `cmd/server/main.go` | 启动模拟器 goroutine |

## 4. 为什么这样设计

- **Middleware 分层**：参数校验 → Key 校验 → 额度检查，每层职责单一。后续增加 JWT 认证只需新增另一个中间件。
- **先写 MySQL（同步），再更新 Redis（异步）**：Redis 挂了不影响 API 正常返回。goroutine 中的 Redis 更新失败只记日志。
- **模拟器复用 Chat Service**：不重复写生成逻辑，保证手动 API 调用和模拟器生成的数据特征一致。
- **OpenAI 兼容格式**：响应体含 `id`/`object`/`model`/`choices`/`usage`，现有 OpenAI SDK 可直接对接。
- **费用计算在 Service 层**：`cost = (prompt_tokens/1000) × input_price + (completion_tokens/1000) × output_price`，精度为 DECIMAL(10,6)。

## 8. 模拟器设计

```go
type Simulator struct {
    ctx    context.Context
    cancel context.CancelFunc
    db     *gorm.DB
    rdb    *redis.Client
}

// Start 启动后台 goroutine
func (s *Simulator) Start() {
    go func() {
        ticker := time.NewTicker(randomInterval(3s, 6s))
        defer ticker.Stop()
        for {
            select {
            case <-s.ctx.Done():
                return
            case <-ticker.C:
                s.generateOne()   // 复用 chat_service
                ticker.Reset(randomInterval(3s, 6s))
            }
        }
    }()
}
```

模型权重：Qwen2.5-72B(高) > Qwen2.5-Coder(中高) > DeepSeek-V3(中低) > MiniMax-Text-01(中) > GLM-4(中)

成功率：97%~99%（按模型稳定性差异化）

## 9. Redis Key 更新清单

每次调用后异步更新以下 Redis Key（全部 INCRBY + EXPIRE 172800）：

```
stats:{date}:total_tokens
stats:{date}:total_requests
stats:{date}:total_cost
stats:{date}:success_count | fail_count | timeout_count
stats:{date}:total_latency_ms
stats:{date}:model:{id}:tokens | requests | latency_ms | cost
quota:key:{key_id}:{date}:tokens | requests
stats:total:total_tokens | total_requests | total_cost
```
