# 阶段 5 设计说明：统计接口开发

> 项目：企业大模型公共服务平台（AI Gateway Console）
>
> 日期：2026-08-07
>
> 状态：🔄 进行中

---

## 1. 阶段目标

实现 Dashboard 所需的全部 6 个统计 API，返回正确的实时数据（Token、请求数、成功率、延迟、成本）。

## 2. 实现内容

| # | 文件 | 说明 |
|---|---|---|
| 1 | `internal/service/stats_service.go` | 统计聚合逻辑（Overview / ModelUsage / Trend / Logs） |
| 2 | `internal/service/model_service.go` | 模型列表 + 今日指标注入 |
| 3 | `internal/handler/stats.go` | overview / model-usage / trend Handler |
| 4 | `internal/handler/log.go` | realtime/logs Handler |
| 5 | `internal/handler/model.go` | models Handler |
| 6 | `internal/router/router.go` | **修改**：注册统计路由 |

## 3. API 清单

| 接口 | 说明 |
|---|---|
| GET /api/stats/overview | 今日/累计 Token、请求数、成功率、延迟、费用 |
| GET /api/stats/model-usage | 各模型 Token + 占比 + 费用 |
| GET /api/stats/trend | 近 7 天汇总趋势 |
| GET /api/realtime/logs?page=&page_size= | 实时日志（分页） |
| GET /api/models | 模型列表 + today 指标 |
| GET /api/health | 增强版（已有） |
